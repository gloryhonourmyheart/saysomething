## 1. 产品定位与核心能力

**一句话定义**：在你说出那句一直不敢说出口的话之前，先让 AI 扮演“你不敢面对的那个人”，替你试一次雷。你看见对方的刺竖起来，改一版，看它软下去；如果你不知道怎么改，它直接给你一句能说出口的话。

**为什么它是 Agent（评审得分点，必须背下来）**

1. **自主干预（Proactive）**：对话中实时监控策略与防御分。连续 3 轮「要求/解释」且防御 ≥ 4，Agent 会**跳出角色**提示，并且一场只打断一次，不抢戏。
2. **长期记忆（Memory）**：读取 SQLite 历史，开场主动问候：“上次你和妈妈从 5 分走到了 2 分，今天想接着聊吗？”
3. **生成式工具（Generative Tool）**：小抄不是固定文案，而是**按档位规则 + 从双方原话抽细节 + 模型润色**现场生成，再落库复用。
4. **确定性工具层（Tools）**：`scenes.py`（场景/台词检索）、`hints.py`（小抄生成与校验）、`charts.defense_curve`（曲线）、`coach.critique`（规则点评）、`insight.build_profile`（画像统计）、`db.*`（CRUD）——全是本地函数，模型只负责“扮演 + 分类 + 打分 + 润色一句话”。

> 答辩口径：**模型负责模拟，代码负责约束。** 一次调用返回结构化 JSON，其余判断全部由本地规则兜住，所以现场不崩、分数可复现、小抄不会空。

## 2. 用户与核心场景

- **用户**：25–40 岁，有话说不出口的人——成年子女、伴侣、职场人、以及想挽回一段友情的当事人。
- **痛点**：第一句话错了，后面就谈不下去；用户缺乏对自己“沟通暴力”的觉知，也没有第二次机会。**更常见的卡点是：知道错了，但张不开嘴说第二句。**

| # | 场景 | 角色设定 | 防御机制 | 一句话诱因 |
|---|---|---|---|---|
| A | 适老化改造（默认） | 68 岁独居母亲，自尊心强 | 被当成“老了、不中用”就竖刺，把话推回给你 | 浴室装扶手 |
| B | 伴侣谈钱 | 34 岁中层，怕被说没本事 | 回避型：冷战、转移话题、用“忙”推开 | 每月开销与还贷分摊 |
| C | 职场谈加薪 | 45 岁创业老板 | 控制型：质疑状态、画大饼、PUA | 调薪 |
| D | 挚友冷战 | 认识十年的挚友，表面洒脱、内心敏感 | 说气话、翻旧账、冷战回避 | 一件小事后的隔阂 |

### 2.1 挚友冷战 · 场景卡

- **场景名**：挚友冷战（练习把话说明白）
- **角色**：认识十年的挚友（许飞/厉娜式特质：表面洒脱，其实内心敏感，遇到冲突容易说气话或选择冷战回避）
- **用户身份**：想挽回这段友谊的当事人
- **介绍文案**：**“十年友情，不该死于不会说话。这次，换你来主动把话说明白。”**
- **防御机制**
  - 5 分（反击）：说反话、翻旧账——“行了，反正你一直觉得我不够好。”
  - 3 分（回避）：冷漠、敷衍——“随便你吧，我都行。”“算了吧，不想说了。”
  - 1–2 分（松动）：试探、给台阶——“你以前不是这样的啊……你到底怎么想的？”
- **专属规则（重要，演示时可讲）**：如果用户只丢一句“我们和好吧”，防御分**卡在 3 分不动**，直到用户把话说明白——讲事实 + 说感受 + 提需求。这条规则由 `scenes.py` 里的 `guard` 函数本地执行，不依赖模型自觉。

## 3. 核心机制：刺与泡沫

产品只做一件事：**让“刺竖起来”和“刺软下去”在屏幕上可见。**

1. **用户输入**：原始措辞（通常带“要求感”）。
2. **Agent 回弹**：扮演对方，回一句带防御的话，同时给出**策略标签**（要求/解释/共情/回避）与**防御分**（1–5）。
3. **视觉反馈**：气泡下方 8px 进度条，暗玫瑰红（高）→ 燕麦黄（中）→ 鼠尾草绿（低）。
4. **顿悟时刻**：高压防御下用户仍不改策略时，Agent 强行打断；同时右栏给出小抄。
5. **终极复盘**：防御曲线 + 策略分布 + 长期画像。

**防御档位与台词档位的硬约束**：防御 5 只能用 tier_5 锚点句，4 用 tier_4……1 用 tier_1。允许改三五个字贴住上下文，不许跨档借语气。`evidence` 字段必须写明 `tier_N`，代码会校验并在缺失时本地补齐——这样“分数”和“语气”不会打架。

### 4.1 F17 小抄 · 设计说明（本次新增）

**是什么**：对方防御 ≥4 时，右栏出现一张卡片——**「🚨 她正在气头上 · 你可以这么说」**，下面一句话；点「就用这句发过去」直接把这句话发给对方，用户不用再打字。它是「演练」和「真实生活」之间的桥：用户不用自己想第二句。

**三层结构（缺一层都不成立）**

| 层 | 做什么 | 失败时会怎样 |
|---|---|---|
| L1 本地规则 | 按防御档位选一套写法 + 从双方原话抽细节 + 三个句式轮换 | 不会失败；断网也有 |
| L2 模型润色 | 单独一次调用（temperature 0.7，不复用主对话提示词），输出 `copy` 和 `keeps`（保留了你哪个细节）；“删掉了哪个施压成分”由本地按策略生成，不让模型自由发挥 | 空返回、超时、脏 JSON、太长、含禁句、和上一张太像 → 退回 L1 |
| L3 生成一次存起来 | 提交那一轮生成，写入 `turns.copy`；渲染层只读 | 老会话没有就现场补一句 L1 |

**档位规则（写进代码，不写示例句）**

| 她的档位 | 小抄该干什么 |
|---|---|
| 5 暴怒反击 | 接住指控，不辩解；承认她话里的具体事实；不解释、不反驳 |
| 4 明显防御 | 撤掉“安排/命令”，把决定权还回去；给一个可撤销的小步 |
| 3 试探犹豫 | 命名她的顾虑，用问句，不替她定义 |
| 2 松口保面子 | 给台阶 + 留退路；给具体动作，不催 |
| 1 卸下防备 | 落到具体动作 / 时间 / 选择权 |

> UI 目前只在防御 ≥4 时展示，1–3 档先把规则写好备用，不做过度设计。

**为什么要“生成一次、存起来”**

Streamlit 每次 rerun 都会重跑侧栏。如果在渲染时调模型，小抄会在同一轮里变来变去，延迟和成本翻倍，断网直接没词。所以：**提交时生成一次 → 写进 `turns.copy` → 渲染只读**。刷新、切场景回来、导出报告，看到的都是同一句。

**本地校验（不信任模型）**

- 长度 8–52 字；
- 禁句表：通用安慰、鸡汤、教科书句式（“我理解你的感受”“别生气”“我是为你好”）；
- 和上一张小抄不能像：开头 4 个字相同，或字符 2-gram 相似度 > 0.4，就算像，重试一次；
- 必须“落地”：句子要和她的原话、或你的原话至少共 2 个汉字，防止模型自由发挥；
- 最多 2 次尝试，累计 8 秒就放弃；两次都不过 → 用 L1 本地版。

**为什么不禁「我知道……但……」**

这是产品的招牌句式，也是目前效果最好的一句。要禁的是**空的承认**（“我知道你不容易”“我是为你好”）——规则是：可以承认，但必须接一个具体细节。

**验收（缺一条不算过）**

1. 同场景，「必须装」vs「我下周出差」→ 小抄不同，且能指回你原话里的细节。
2. 她最后一句不同（「你别管我」vs「你要真惦记我」）→ 小抄开头不同。
3. 5 档 vs 2 档 → 写法不同（5 不辩解，2 给台阶）。
4. 断网 / 超时 / 脏 JSON → 仍出 L1 小抄，页面不崩。
5. 刷新页面 → 同一轮小抄不变。
6. 连说三句要求 → 干预只出现一次，且引用的是用户真实原话。
7. 换到老板 / 挚友场景 → 小抄里不出现「长辈」「她」这类串味词。

## 6. 答辩四问与防杠话术（B 必背）

**Q1 为什么这不是聊天机器人？**
> “聊天机器人聊完就忘，没有记忆，也没有干预。我们的 Agent 有长记忆（SQLite 落库），而且它会在你一意孤行时**主动叫停你**；叫停之后还给你一句能说出口的话。它不是在陪你聊天，它是在追踪并纠正你的沟通模式。”

**Q2 为什么不是沟通训练 App？**
> “课程教技巧，我们让你亲手试错。你看着防御曲线从 5 分掉到 2 分，这种视觉冲击是任何课程都给不了的；小抄则把‘技巧’变成了‘这一句’。”

**Q3 防御分凭什么信？**
> “凭它是 1–5 的整数，有明确锚点，并且被规则约束：防御 5 只允许说 tier_5 的句子，`evidence` 必须写明用了哪一档，代码还会二次校验。我们交付的不是绝对分数，而是‘同一件事换个说法，分数掉了下来’这个事实。”

**Q4 能规模化落地吗？**
> “内核不变，换场景数据即可——今天四个场景，明天可以是校园、医患、客服。对外它是机构评估师的上门前预演工具，对内是用户的私人沟通助理。”

**Q5 小抄是不是提前写好的模板？**
> “不是。它先按对方当前防御档位选一套**写法**（该接住、该还决定权、还是该给台阶），再从你刚说的话里抓一个具体细节——时间、地点、动作、数字；所以你换一句输入，小抄就换一句。模型只负责把它改得更像人话，模型挂了就退回本地规则版，卡片不会空。”

**可能的追问 → 一句话挡回去**

| 追问 | 回答 |
|---|---|
| 防御分有科学依据吗？ | 它是产品化的标尺，不是心理测量量表；我们保证的是**相对变化**可复现。 |
| 会不会教坏用户？ | 我们的目标是让对方愿意听下去，不是操控；产品边界写了“不是心理咨询”。 |
| 模型胡说了怎么办？ | JSON 校验 + 二次重试 + 离线兜底；小抄另有长度、禁句、相似度、相关性四道本地校验，不过就退回规则版。 |
| 小抄会不会每张都一样？ | 三个句式按上一张轮换，且相似度超阈值就重试；同一场景连点两次不会给同一句。 |
| 数据隐私？ | 全部本地 SQLite，不上传、不做账号，赛后清库。 |
| 为什么用 Streamlit？ | 24 小时里它让我们把时间花在机制上而不是前端工程上，这是克制的选择。 |

## 7. 技术架构

```
用户输入
  └─ app.py（对话流 / 侧栏 / 复盘）
       ├─ agent.run_turn(text, history, scene)
       │    ├─ scenes.render_system_prompt(scene)   # Prompt 由数据渲染
       │    ├─ 一次 DeepSeek 调用（deepseek-flash）
       │    │    └─ {"reply","strategy","defense","evidence"}
       │    ├─ 校验：parse → validate → clamp_defense → normalize_evidence
       │    └─ guard（场景专属规则，如挚友的 3 分锁定）
       ├─ hints.suggest(scene, turns, defense, last_copy)   # 小抄，只在提交时跑一次
       │    ├─ L1 fallback_copy()   本地规则：档位 + 抽双方原话细节
       │    ├─ L2 polish()          单独一次调用；空/脏/太长/太像 → 回落 L1
       │    └─ 结果写进 Turn.copy_text
       ├─ db.add_turn()          # 每轮落库（同轮 upsert，含 copy 列）
       ├─ charts.defense_curve() # Plotly 渐变曲线
       ├─ coach.critique()       # 规则点评
       └─ insight.build_profile()# 画像（纯统计，不调模型）
```

**关键决策**

| 决策 | 理由 |
|---|---|
| 单次调用同时产出 reply/strategy/defense | 三者必须自洽，拆成三次会互相打架，也拖慢演示 |
| 结构化 JSON + 三级解析 + 一次重试 + 离线兜底 | 现场网络与模型都不确定，只有降级路径是确定的 |
| 分数由代码夹取，不由模型自由发挥 | 可复现性就是评分表里的“结果可验证” |
| 小抄「生成一次、存库、只读」 | Streamlit 会反复 rerun；渲染时调模型会让同一轮小抄变来变去 |
| 小抄模型层独立参数（temperature 0.7） | 主对话要稳定 0.3，改写要多样；两件事不能共用一套参数 |
| 场景数据驱动 Prompt | 加场景 = 加一个 dataclass，不改业务代码 |
| Streamlit | 省掉前端工程，24 小时内的正确取舍 |

## 8. 数据模型

```sql
sessions(id INTEGER PK, scene_name TEXT, created_at TEXT)
turns(id INTEGER PK, session_id INTEGER, round INTEGER,
      user_text TEXT, reply TEXT, strategy TEXT, defense INTEGER,
      evidence TEXT, latency_ms INTEGER, copy TEXT, created_at TEXT,
      UNIQUE(session_id, round))
```

- `copy` 存这一轮的小抄原文；老库启动时自动补列（迁移只加列，不重建）。
- 全部 CRUD 都包了 try/except：数据库坏了也只返回空，页面不崩。
- `scene_name` 存中文 label，`scenes.key_of()` 反查 key，脏数据自动回退默认场景。

## 9. 风险与降级

| 风险 | 表现 | 预案 |
|---|---|---|
| 断网 / API 抽风 | 回弹变成兜底文案 | 顶部提示条 + 切 `app_ui_mock.py`（纯离线假数据） + 备份录屏 |
| 模型输出不合规 | 解析失败 | 重试一次 → 仍失败则降级为纯文本回弹，不中断 |
| **小抄模型层返回空 / 超时** | 已处理：失败重试 2 次、8 秒放弃，自动回落 L1 | 本地规则版一直在跑，卡片不会空；真机不稳就 `SAY_COPY_MODEL=0` |
| **提示词串味**（长辈/她） | 已修：提示词改用 `role_name` / `speaker` / `dialogue` 渲染 | 4 场景各验收一次（老板、许飞重点看） |
| 演示超时 | 每 30 秒扣 2 分 | 手卡掐表，问答才讲挚友场景 |
| 投影看不清 | 后排看不见分数 | 大字号 + 高对比；分数用大数字 |
| 数据库被写坏 | 页面报错 | 侧栏「清空历史」+ 自动重建表 |
