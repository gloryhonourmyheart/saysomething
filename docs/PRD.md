## 0. 当前状态（以代码和测试为准）

v3.2 的核心变化不是“再加一个功能”，而是把**台词、档位、反应标签的权威**从模型手里拿回服务端：

- 模型只返回 `strategy` + `anchor_id`，不再写 `reply` / `defense` / `evidence`。
- 服务端用 `AnchorLine` 决定这一轮说哪句、几分、什么 reaction。
- `rules.constrain_defense` 负责因果：要求/回避不降、解释最多降 1、共情才允许大降。
- 最终 `defense_score` 必须等于最终台词 `tier`，`reply_text` 必须等于最终台词 `text`。

## 1. 产品定位与核心能力

**一句话**：在你说出那句一直不敢说出口的话之前，先让 AI 扮演“你不敢面对的那个人”，替你试一次雷。你看见对方的刺竖起来，改一版，看它软下去；如果你不知道怎么改，它直接给你一句能说出口的话。

**为什么它是 Agent（评审得分点）**

1. **自主干预（Proactive）**：连续 3 轮「要求/解释」且防御 ≥4，Agent 跳出角色叫停；一场只打断一次。
2. **长期记忆（Memory）**：读 SQLite 历史，开场引用上一场“从几分走到几分”。
3. **生成式小抄（Generative Tool）**：按档位规则生成一句能直接发出去的话；提交时生成一次、落库、渲染只读。
4. **确定性工具层（Tools）**：`scenes.py`、`rules.py`、`charts.py`、`coach.py`、`insight.py`、`db.py` 全是本地函数。

> 答辩口径：**模型负责模拟和选锚点，代码负责约束。** 模型可以选错，但不可能把 5 分暴怒标成 3 分。

## 2. 四个场景

| # | 场景 | 角色 | 防御机制 | 诱因 |
|---|---|---|---|---|
| A | 适老化改造（默认） | 68 岁独居母亲 | 被说“老了、不中用”就竖刺 | 浴室装扶手 |
| B | 伴侣谈钱 | 34 岁中层 | 回避、冷战、转移话题 | 每月开销与还贷 |
| C | 职场谈加薪 | 45 岁创业老板 | 质疑状态、画大饼、PUA | 调薪 |
| D | 挚友冷战 | 认识十年的挚友 | 说气话、翻旧账、冷战 | 一件小事后的隔阂 |

**挚友专属规则**：只丢一句“我们和好吧”，防御卡在 3 分；讲事实 + 说感受 + 提需求才继续动。由 `scenes.py` 的 `guard` 本地执行，优先级最高。

## 3. 核心机制：刺与泡沫

### 3.1 一轮的权威链

```
用户输入
  → 模型只返回 {"strategy": "...", "anchor_id": 12}
  → scenes.anchor(anchor_id) 取 AnchorLine(text/tier/reaction)
  → rules.constrain_defense(prev, strategy, line.tier) 算允许档位
  → scene.guard(...) 场景规则覆盖（挚友卡 3 分）
  → 若档位变了，scene.line_for_tier(...) 在该档重选一句
  → defense_score = 最终台词.tier；reply_text = 最终台词.text
```

**锚点缺失时**：先按用户最后一句和全库台词做本地字符重叠相似度（至少 3 个重叠字），命中就用那句；仍不命中才用 tier5 兜底。模型不再返回 reply，所以相似度输入是“用户最后一句”，不是模型写的回弹。

### 3.2 因果规则

| 策略 | 规则 | 目的 |
|---|---|---|
| 要求 | `max(上一轮, 本轮)` | 硬话不会让防御下降 |
| 回避 | `max(上一轮, 本轮)` | 躲开也不会自动变好 |
| 解释 | `max(上一轮 - 1, 本轮)` | 解释只配降一格，不能一句洗白 |
| 共情 | `min(上一轮, 本轮)` | 只有共情允许大降 |

最终分数永远等于最终台词所在档位。宁可覆盖模型选择，也不出现“分数 3、台词 5”。

### 3.3 视觉

- 五格圆点：实心＝当前分，空心＝剩余；不用细长进度条。
- 颜色：5 `#8C3B45` 暗玫瑰红 / 4 `#B8615B` 砖红 / 3 `#D9B36A` 燕麦黄 / 2 `#8FAE8B` 鼠尾草绿 / 1 `#2F6B4F` 深绿。
- 状态行左边“你的表达：要求”，右边“她的防御：5/5 · 反击”。
- 对话流潜台词默认折叠；Dashboard 集中默认展开。
- 头像：`assets/user.png`、`assets/aging.png`、`assets/money.png`、`assets/salary.png`、`assets/bestie.png`、`assets/coach.png`；读取失败回落 🧑/👵/🤖，不白屏。

### 4.1 F17 小抄

**三层**

| 层 | 做什么 | 失败时 |
|---|---|---|
| L1 本地规则 | 按档位选 `{m}` 模板；`{m}` 只来自用户最后一句的实词 | 不会失败；断网也有 |
| L2 模型润色 | 单独一次调用，temperature 0.7；只输出 `copy` / `keeps` | 空/脏/太长/太像/含引号/场景词幻觉/新增数字 → 回落 L1 |
| L3 存一次 | `_submit` 生成，写入 `Turn.copy_text` 和 `turns.copy` | 老数据为空时现场补 L1 |

**L1 的铁律**

- 模板只用 `{m}`，不再引用对方原话；提不到具体词时用中性句。
- 不出现 `copy_brief` / `scenario` 的初始场景词（例如“扶手”）。
- 不出现 `「」`、`[]`、任何引号；句子必须能直接复制发送。

**L2 的铁律**

- 只准聊“用户最后一句”和“对方最后一句”正在聊的事，禁止拉回初始场景。
- 禁止任何引号引用原话，必须用陈述句或自然短句复述。
- 本地校验：长度 8–52 字、禁句、与上一版相似度、场景词泄漏（小抄有、用户最后一句没提 → 判幻觉）、新增数字（原话没有 → 判幻觉）。
- 最多 3 次尝试，累计 12 秒放弃；仍失败回落 L1。

**为什么不是模板**：L1 只给“写法”和用户原话里的具体词；L2 把它改成人话。换一句输入，`{m}` 就变；换对方一句，档位和语气就变。

| 时间 | 动作 | 口播 |

## 6. 答辩四问与防杠

**Q1 为什么不是聊天机器人？**
> 有 SQLite 长期记忆，会在你连续硬话时主动叫停；叫停后还给一句能直接发出去的话。它追踪并纠正沟通模式，不是陪聊。

**Q2 为什么不是沟通训练 App？**
> 课程教技巧，我们让你亲手试错；防御曲线从 5 掉到 2 的视觉冲击，课程给不了。

**Q3 防御分凭什么信？**
> 模型只选锚点，分数由服务端 `AnchorLine` 的 tier 决定；`constrain_defense` 再做因果约束；最终分数必须等于最终台词档位。5 分暴怒不可能被标成 3 分。

**Q4 能规模化吗？**
> 内核不变，换场景数据即可；今天四个场景，明天可以是校园、医患、客服。

**Q5 小抄是不是提前写好的？**
> 不是。L1 按档位选写法、从你最后一句抓具体词；L2 只负责改成人话。换输入就变；模型挂了回落 L1，卡片不会空。小抄里没有引号，是能直接发出去的人话。

**Q6 为什么解释只降一格？**
> 解释常常是“我都是为你好”的变体，如果一句解释就清零，产品会教用户用解释逃避责任。要求/回避不降、解释最多降一格、共情才允许大降，这是产品的价值观。

| 追问 | 回答 |
|---|---|
| 防御分科学吗？ | 产品化标尺，不承诺心理测量；承诺的是相对变化可复现。 |
| 模型胡说？ | 只认 strategy/anchor_id；JSON 两次不合规就 tier5；小抄还有本地校验。 |
| 小抄会重复？ | L1 三句式轮换 + 相似度校验；L2 失败回落，仍不空。 |
| 数据隐私？ | 本地 SQLite，不上传、不做账号，赛后清库。 |

## 7. 技术架构

```
app.py（对话流 / 右栏 / 复盘）
  ├─ agent.run_turn(text, history, scene)
  │    ├─ scenes.render_system_prompt(scene)     # 台词库编号 + 只问 strategy/anchor_id
  │    ├─ 一次 DeepSeek 调用（deepseek-flash）
  │    │    └─ {"strategy": "...", "anchor_id": 12}
  │    ├─ validate_payload → 只认 strategy + anchor_id
  │    ├─ scene.anchor / match_anchor / fallback_anchor
  │    ├─ rules.constrain_defense
  │    ├─ scene.guard（挚友卡 3 分）
  │    └─ scene.line_for_tier → Turn
  ├─ hints.suggest(...)      # 提交时生成一次，写 Turn.copy_text
  ├─ db.add_turn(...)        # turns 含 anchor/reaction/delta_reason/key_phrase/copy
  ├─ charts.defense_curve()  # 五色点线 + 绿/红因果圈
  ├─ coach.critique()        # 规则点评
  └─ insight.build_profile() # 画像统计
```

**关键决策**

| 决策 | 理由 |
|---|---|
| 模型只选锚点，不写台词/分数 | 信任危机只能靠“服务端唯一权威”解决 |
| 档位冲突时重选台词 | 宁可覆盖模型，也不出现分数与台词打架 |
| 解释最多降 1 | 防止“解释一句就洗白” |
| 小抄生成一次存库 | Streamlit 反复 rerun，渲染时调模型会变来变去 |
| 小抄去引号 | 真实聊天里没人用「」复述对方；要能直接复制发送 |
| 头像失败回落 Emoji | 视觉是装饰，绝不能白屏 |

## 8. 数据模型

```sql
sessions(id INTEGER PK, scene_name TEXT, created_at TEXT)

turns(id INTEGER PK, session_id INTEGER, round INTEGER,
      user_text TEXT, reply TEXT, strategy TEXT, defense INTEGER,
      evidence TEXT, stage TEXT, subtext TEXT, fear TEXT,
      anchor INTEGER, reaction TEXT, delta_reason TEXT, key_phrase TEXT,
      copy TEXT, latency_ms INTEGER, created_at TEXT,
      UNIQUE(session_id, round))
```

- `anchor` 存 Prompt 里的台词编号；`reaction` 存“反击/硬挡/试探/松口/接受”。
- `delta_reason` 存这一轮为什么升/降（因果规则或 guard）；`key_phrase` 存用户关键句。
- 老库启动时 `_migrate` 自动 ALTER 补列，只加列不重建；历史行默认空。
- 所有 CRUD 包 try/except：数据库坏了返回空，页面不崩。

## 9. 风险与降级

| 风险 | 表现 | 预案 |
|---|---|---|
| 断网 / API 抽风 | 回弹走 tier5 兜底 | `agent._fallback` 仍用台词库；小抄回落 L1 |
| 模型输出不合规 | 两次脏 JSON | 直接 tier5，不编造 |
| 小抄 L2 空/超时 | 卡片仍是 L1 | `SAY_COPY_MODEL=0` 可完全关掉模型层 |
| 相似度误命中 | 兜底台词不贴当前语境 | 只在缺失 anchor 时用；至少 3 字重叠；仍不放心就删掉这一层直接 tier5 |
| 投影看不清 | 后排看不见颜色 | 15px 圆点 + 高对比五色 + 大数字 |
| 数据库写坏 | 页面报错 | 侧栏清空历史 + 自动重建表 |

## 附录：产品边界

本产品仅用于沟通情景仿真演练，不是心理咨询、家庭治疗或医疗辅助工具，不提供诊断与治疗建议。小抄是措辞建议，不构成操控建议。回访为本地模拟，不涉及真实定时推送；数据仅存本机 SQLite。
