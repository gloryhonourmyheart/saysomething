0. 现在打开页面就能看到什么

  1. 输入一句硬话 → 对方回一句台词库里的原句；右边五个圆点显示防御分，左边是策略胶囊。
  2. 连续三句「要求/解释」且防御 ≥4 → Agent 跳出角色叫停；一场只叫一次。
  3. 防御 ≥4 时，右栏出现小抄卡片；点「就用这句发过去」直接替你发出去。
  4. 小抄没有引号，是能直接复制发送的人话；换一句输入，句子就变。
  5. 照着小抄说 → 分数掉下来，曲线出现落差；绿圈标“关键软化句”，红圈标“再次施压”。
  6. 打开【沟通体检报告】→ 走势 + 饼图 + 点评 + 默认展开的潜台词。
  7. 4 个场景随便切；聊多少轮都行；刷新不丢；上次来过，开场会提一句“上次从几分走到几分”。
